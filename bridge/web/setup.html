Lamp clocks

The bridge sets every lamp's clock each night at 03:30. After a power cut, set them now. The lamps are unreachable for about 15 s per lamp while this runs.

Scenes

Import a settings file exported by the Lamp Control page (Settings file → Export file). Its scenes and/or presets replace the bridge's; schedules in it are ignored. Presets are named light settings for the Kindle, e.g. "presets": [{"name": "Evening", "white": 2200}, {"name": "Red", "colour": {"hue": 5, "saturation": 90}}].

Lamps

The lamp list comes from lamps.json on GitHub Pages (add lamps with tools/scan-lamps.swift on the Mac).
